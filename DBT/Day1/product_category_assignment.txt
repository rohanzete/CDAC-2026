-- Product & Category Assignment Database
-- MySQL

DROP DATABASE IF EXISTS product_assignment;
CREATE DATABASE product_assignment;
USE product_assignment;

CREATE TABLE category (
    cid INT PRIMARY KEY,
    category VARCHAR(50) NOT NULL,
    description VARCHAR(255)
);

CREATE TABLE product (
    pid INT PRIMARY KEY,
    pname VARCHAR(100) NOT NULL,
    qty INT NOT NULL,
    mfgdate DATE NOT NULL,
    expdate DATE NOT NULL,
    cid INT,
    FOREIGN KEY (cid) REFERENCES category(cid)
);

PRODUCT & CATEGORY SQL ASSIGNMENT
================================

Tables:
1. category(cid, category, description)
2. product(pid, pname, qty, mfgdate, expdate, cid)

Instructions:
- Write one SQL SELECT query for each question.
- Do NOT use JOINs.
- Do NOT use nested/subqueries.
- Do NOT use SQL functions.
- Practice arithmetic operators (+, -, *, /, %), comparison operators,
  logical operators (AND, OR, NOT), BETWEEN, IN, and related operators.
- Use only the two tables given above.

20 QUESTIONS
------------

1. Display the product name and quantity of all products whose quantity is
   greater than 20.

2. Display pid, pname and qty for products whose quantity is less than or
   equal to 15.

3. Display pname and a calculated column showing the quantity after adding
   10 units to the current quantity.

4. Display pname and a calculated column showing the quantity after removing
   5 units from the current quantity.

5. Display pname and a calculated column showing double the current quantity.

6. Display pname and a calculated column showing half of the current quantity.

7. Display pid, pname and qty for products whose quantity is between 10 and 30.

8. Display all products whose quantity is NOT between 10 and 30.

9. Display products belonging to category IDs 1, 3, or 5 using the IN
   operator.

10. Display products whose category ID is NOT IN 2, 4, and 6.

11. Display products whose quantity is greater than 20 AND category ID is 1.

12. Display products whose quantity is less than 20 OR category ID is 5.

13. Display products whose quantity is between 10 and 30 AND category ID is
    either 1 or 3.

14. Display products whose quantity is greater than 40 OR quantity is less
    than 10.

15. Display products whose quantity is greater than 15 AND quantity is less
    than 50 AND category ID is 1.

16. Display products manufactured between '2025-02-01' and '2025-06-30'
    using the BETWEEN operator.

17. Display products whose expiry date is NOT between '2027-01-01' and
    '2028-12-31'.

18. Display products whose quantity, when divided by 5, has remainder 0.
    Use the modulo (%) operator.

19. Display products whose quantity is greater than 20 AND whose category ID
    is NOT 2.

20. Display products where either:
       - quantity is between 10 and 20 AND category ID is 1,
       OR
       - quantity is between 30 and 50 AND category ID is 2.
